Use a fake provider with the actual cell entry point and an isolated process with synthetic secrets. Exercise pass, decoy, refusal, missing reply, malformed response and stop paths. The fake service supplies no capability evidence. Hold a real process at a committed reservation, interrupt it and reenter through the live CLI. No second dispatch can use that reservation.

## Failure And Recovery Rules

| Operation and commit | Ownership and interruption result |
| --- | --- |
| Qualify and enroll | Verify a clean runner, the operating profile, all public commitments and ten originals. A partial enrollment can't authorize calls. |
| Start cell or reserve provider call | A lock and durable unique cell and call keys fence writers. Count unresolved reservations toward limits. A restarted active cell stays held for inspection. |
| Send and receive | Disable redirects and automatic retries. Unknown delivery, missing usage, changed service or excess usage stops collection. Preserve the observation. |
| Apply and score | Record selection before the one target replacement. A stop before observed completion holds the cell. Independent scoring uses selected bytes after the candidate stops. |
| Report or reconcile | Check the original freeze, full assignment denominator and observed evidence. Missing receipts, native billing, mandatory checks or paired results keep the larger-study decision unresolved. |
